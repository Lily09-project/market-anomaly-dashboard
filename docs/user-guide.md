# 使用者指南

## 四個主要頁面

- **股票分析**：查看市場指數、熱門股、個股技術證據、近期變化與同業脈絡。
- **市場雷達**：依產業與研究配置，使用透明的四因子分數整理研究優先序。
- **異常偵測展示**：獨立檢視資料工程與異常標記流程；異常事件不是投資訊號。
- **快照比較**：離線比較同一股票的兩份 Research Snapshot JSON，並驗證內容完整性。

頂部導覽會將目前頁面寫入網址。股票分析頁也會將目前代號寫入 `symbol`，因此網址可以直接分享，例如：

```text
/?page=stocks&symbol=2330.TW
/?page=radar
/?page=compare
```


## 市場雷達操作方式

1. 在側欄選擇產業、研究配置、最低證據分數與候選池規模。候選池來自熱門代表清單，不是全市場掃描。
2. 先確認頁面狀態是 `LIVE`、`部分連線` 或 `DEMO`，再閱讀排序。
3. 排名卡呈現前三名的主要證據；完整表格保留四項分數、RSI、量比、波動率與資料日。
   若同批資料同時含 LIVE 與 DEMO，排名只比較 LIVE；全部離線時才使用 DEMO。
4. 「評分方法與限制」列出每項因子的計算邏輯。至少需要 60 個交易日，資料不足的標的不納入排序。

市場雷達只整理研究順序，不預測報酬，也不提供買進、賣出或持有建議。

篩選條件會同步到網址，因此重新整理頁面或分享連結後仍能還原同一組研究條件。

## 如何判讀資料狀態

| 狀態 | 意義 | 使用方式 |
| --- | --- | --- |
| `LIVE` | 行情由 yfinance 取得 | 仍應確認畫面上的「資料截至」日期 |
| `部分連線` | 部分行情已降級 | 逐卡確認 `LIVE` 或 `DEMO` 標籤 |
| `DEMO` | 示範資料，非真實行情 | 只用來體驗介面與研究流程 |
| `離線` | 沒有可用行情 | 使用「重新取得資料」或稍後再試 |

行情快取最長 15 分鐘。交易休市、供應商限制、網路中斷或代號不存在，都可能讓最新資料日早於今天。

## 隱私與資料處理

- 本產品不需要帳號，也不收集姓名、Email 或投資組合。
- 自訂股票代號只用來向行情來源查詢，不會建立使用者紀錄。
- 快照比較在記憶體中完成；上傳的 JSON 不寫入磁碟，也不傳送至外部服務。
- 下載的 JSON 與 HTML 由瀏覽器接收，使用者自行保管。

## 使用限制

本產品不提供買賣建議、目標價、獲利保證或價格預測。技術證據描述歷史價格與成交量狀態，不代表因果關係，也不能保證未來表現。
