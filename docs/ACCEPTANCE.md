# Market Regime Lab — 驗收規格

本文件在重做開始前訂定，是判斷專案「完成」的唯一標準。每一條驗收項目都對應到可自動執行的測試，
最終 PR 必須逐條附上證據（測試名稱或 CI job），全部通過才算完成。

## 0. 範圍與架構決策

| 項目 | 決策 |
| --- | --- |
| 資料 | 預設使用可重現的合成行情（固定種子），以已知的市場狀態切換（平穩／高波動／趨勢）產生，方便驗證演算法；保留 yfinance／TWSE adapter，但展示站不依賴它 |
| 分析核心 | Python（`src/`），新增 `src/analytics/`，以 numpy 自行實作演算法（不依賴黑盒套件），全部可離線、可重現 |
| 前端 | 全新 React + TypeScript + Vite 靜態網站（`web/`），部署於 GitHub Pages |
| 舊版 Streamlit | 移除，由新網站與新測試取代 |
| 誠實標示 | 全站標示「合成資料、研究用途、非投資建議」；所有績效數字同時呈現樣本外結果 |

## 1. 功能驗收（創新功能）

### F1 標的總覽
- 價格、報酬、波動率圖，並以背景色帶疊加偵測到的市場狀態；可切換標的與期間。
- 驗收：E2E 切換標的後圖表與摘要同步更新，網址保存狀態。

### F2 市場狀態偵測（隱藏馬可夫模型）
- 以 numpy 實作高斯 HMM（Baum-Welch + Viterbi），每個標的 2–3 個狀態。
- 輸出狀態時間軸、轉移矩陣、各狀態平均報酬／波動與預期持續天數。
- 驗收（單元測試）：
  - 轉移矩陣每列和為 1；
  - 對數概似在 EM 迭代中不遞減；
  - 合成資料的已知狀態，Viterbi 還原準確率 ≥ 80%（標籤對齊後）。

### F3 異常事件研究
- 偵測異常日，並計算事件前後 [-5, +10] 日的累積異常報酬（CAR），附 bootstrap 95% 信賴區間。
- 誠實回答「異常日之後是否有可預測的報酬」。
- 驗收：
  - CAR 計算以手算小例子驗證；
  - 在純雜訊資料上，信賴區間涵蓋 0。

### F4 誠實回測實驗室
- 對均線交叉策略做參數網格搜尋，並排顯示樣本內與 walk-forward 樣本外的績效熱圖。
- 以 CSCV 計算 **回測過度擬合機率（PBO）** 與 Deflated Sharpe Ratio，示範「漂亮回測」為何不可信。
- 驗收（單元測試）：
  - 純隨機漫步資料的 PBO ≥ 0.4；
  - 含真實可預測訊號的合成資料 PBO 明顯較低；
  - walk-forward 切分不重疊，且無前視偏誤（測試會刻意注入未來資訊並確認被拒絕）。

### F5 壓力測試（瀏覽器 Monte Carlo）
- 以區塊 bootstrap 在 Web Worker 中模擬未來 60 個交易日的路徑，顯示扇形圖、VaR／CVaR（95%、99%）。
- 使用者可調整區塊長度、路徑數與期間，可取消並顯示進度。
- 驗收：
  - 固定種子結果完全相同；
  - VaR／CVaR 以已知分布驗證；
  - CVaR ≥ VaR（以損失表示）。

### F6 研究快照與比較
- 匯出包含資料指紋、方法參數與結果的研究快照（JSON），可在瀏覽器上傳兩份快照比較差異。
- 驗收：快照重新匯入後雜湊一致；被竄改的快照會被拒絕並說明原因。

### F7 資料可信度
- 資料來源、種子、SHA-256、方法限制與誤用警告。
- 驗收：E2E 顯示的雜湊與 manifest 一致。
